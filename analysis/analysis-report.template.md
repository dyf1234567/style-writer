## 1. 视角与声音

**看什么**：叙述者站哪里、能进谁的脑子、有没有自己的态度。

- 人称与聚焦类型是？是否存在视角切换，切换的代价（读者是否需要重新定位）如何？
- 叙述距离远近：是紧贴感官（"他看见"），还是允许概括与评论？
- 叙述者有没有"声音"——即脱离人物也能被认出来的语气？如果有，靠什么建立？

**证据**（写章号 + 行号区间，**不抄原文**；必要时只摘 8 字以内的短语）

## 2. 时间与顺序

**看什么**：故事时间与叙述时间的错位。

- 基准顺序是什么，倒叙/预叙各占多少，通常出现在什么位置（章首？高潮前？）
- 时间流速：哪些时刻被放慢到 1:5 以上，哪些被一句带过？放慢的时刻有什么共同点？
- 省略：常省略的是哪种内容（赶路、日常、还是情绪消化期）

**证据**

## 3. 分线结构 ★

**看什么**：几条线、各占多少、怎么切、多久撞一次。

- 线数：同时活跃几条？有没有"休眠线"（沉寂数十章再唤醒）
- 权重：抽样统计 50 章，各线篇幅占比是多少？权重是否随卷变化？
- 切换触发：是在**悬念最强处**切（钩住读者），还是在**情绪落点**切（给缓冲）？
- 过渡手法：硬切 / 时间词 / 尾词钩连？钩连的具体做法是？
- 交汇周期：平均多少章汇合一次？汇合是"人物相遇"还是"信息对撞"？
- 收线方式：支线是单元剧式收干净，还是长弧并入主线？

**证据**

## 4. 连载节奏 ★

**看什么**：这是长篇连载的命门，决定读者能不能追完。

- 章均字数与**篇幅曲线**（前中后是否稳定，高潮期是否变长）
- 章末钩子类型分布（抽样 30 章统计），以及卷首/卷中/卷末的强度差异
- 张弛比：紧张段与松弛段如何交替，一个完整弧跨多少章
- 高潮后的缓冲：用几章、靠什么内容让读者喘气（日常？群像？新悬念？）
- 强断章频率：每多少章来一次"必须点下一章"

**证据**

## 5. 场景与描写

**看什么**：一个场景装多少东西，景物承担什么功能。

- 单场景字数区间，章均场景数
- 景物描写的功能：烘托氛围 / 外化情绪 / 承载信息 / 当节奏刹车
- 感官配比：是否偏视觉？有没有标志性的非视觉感知（气味、触感、体温）
- 展示与讲述的分工：关键时刻用展示，过渡用讲述，边界在哪

**证据**

## 6. 句法与语域

**看什么**：闭上眼睛也能认出的那部分。

- 句长中位数与 p90，**长句铺陈 + 短句收束**是否成固定套路
- 短段占比（<=20 字的段落）——这个数字直接决定"翻页速度"
- 对话占比与对话块密度
- 标点个性：感叹号/省略号/破折号/分号的使用倾向
- 语域：雅俗、行话、方言、半文半白，以及语域是否随视角人物切换

**证据**

## 7. 对白与意象

**看什么**：人物怎么说话，作品反复回到哪些意象。

- 潜台词密度：角色是否常说反话、答非所问、以问代答
- 角色区分度靠什么建立（口癖 / 句式 / 用词 / 信息量）
- 是否借对白交代背景，比例多少
- 高频语义域（写类别，不写具体物象）
- 核心意象的复现间隔与变奏方式：第几次出现时含义翻转

**证据**

---

## 8. 情感书写 ★v2 新增

**看什么**：情绪怎么落地，靠什么承载，压到多满才放。

- 情绪载体：身体反应 / 动作细节 / 景物投射 / 内心独白 / 对白潜台词，哪一种是主力？
- 升级路径：层层加压到临界，还是瞬间爆发后急冷？有没有固定的"起—涨—落"节拍？
- 克制程度：抒情浓度高/中/低（`emotion_words_per_1k` 高≠浓烈，要看是否被动作稀释）。
- 峰值手法：卷内情绪最高点用什么写法托住（切短段？放慢？留白？）——只记手法不记内容。
- 量化参考：`measure` 的 `lexeme.emotion.total_per_1k`（显性情绪词密度）供 [M] 锚定。

**证据**

## 9. 回报节律 ★v2 新增

**看什么**：读者追更的燃料补给节奏——长篇连载与短篇的分水岭。

- 兑现单元：爽点/泪点的最小可复用单元类型（打脸 / 越级取胜 / 身份揭示 / 重逢 / 翻案）？写类型不写具体事件。
- 兑现间隔：平均每隔多少章给一次小回报（`payoff_interval`）。
- 压抑/释放比：埋多大坑填多深（4:1 是常见的"压得久放得响"）。
- 分期方式：一次性结清 / 分层递进兑现 / 故意拖欠到卷末引爆。
- 立 flag 到兑现跨度（`promise_drift`）；弧内回报分布（前低后高 / 双峰 / 末段集中）。

**证据**

## 10. 收敛：从报告到特征卡

逐项把上面的判断翻译成 `style-card.yaml` 的字段。翻译规则：

| 报告里的说法 | 卡片里怎么写 |
|---|---|
| 主角在雨夜被背叛后反杀 | 删掉。这是情节，不是方法 |
| 每三章一个小高潮 | `arc_length: 3`，保留 |
| 章末总断在最紧张处 | `chapter_hook_type: 悬念式`，保留 |
| 文笔很细腻，像刺绣 | `description_ratio: 0.28` + `sensory_mix: 触觉优先`，保留量化部分 |
| 喜欢用"像……一样" | `metaphor_type: 明喻为主`，保留（比喻类型是方法，具体比喻才是表达） |
| 情绪全靠小动作不喊疼 | `emotion_writing.carrier: 动作细节`，保留（手法，不记桥段） |
| 压八章放一章，憋到卷末引爆 | `reward_rhythm.buildup_release_ratio: 8:1` + `installment_style: 故意拖欠至卷末` |
| 口头禅是"忽然""顿时" | `syntax.lexical_fingerprint: [忽然, 顿时]`（通用功能词可进，专名不可） |

## 11. 红线自检

- [ ] `style-card.yaml` 中无任何人名、地名、招式名、组织名
- [ ] 无任何原句、金句、独特点喻
- [ ] 无任何具体情节描述
- [ ] `lexical_fingerprint` 只含通用功能词，不含任何专名
- [ ] `emotion_writing` / `reward_rhythm` 只记手法与频次，不含具体桥段
- [ ] 把卡片给没读过原作的人看，他无法还原出任何一幕场景
- [ ] 卡片能直接驱动生成：拿它写一段全新的故事，读起来像又不像
